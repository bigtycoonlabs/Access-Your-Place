### To Activate Cron Jobs:
1. Go to GitHub repo → Settings → Secrets and variables → Actions
2. Add secret: `SUPABASE_SERVICE_ROLE_KEY`
3. Value: Get from Supabase Dashboard → Settings → API → service_role key
